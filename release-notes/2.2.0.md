- App descriptions on the page now appear in the user's language, for every language the page supports, falling back to English. Nothing to change in your Windows app; if it still translates descriptions itself, it can drop that code.
- Web and Android: `catalog.ts` adds `blurbFor(app, locale)`, which returns an app's description for a locale tag such as `fr-CA` and falls back to English. Use it in place of your own description translations, and drop their message keys.
- The translations are AI-drafted and not yet reviewed by native speakers; README "Languages" tracks their review.
